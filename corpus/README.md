# Corpus — bail-applications collection

Demo case type: **bail applications**. Statute coverage is scoped to bail
provisions + anchoring sections; judgments are bail-disposition cases;
case files are two fictional bail matters.

## What is in the corpus (47 docs)

| Group | Docs | Source | Licence / terms |
|---|---|---|---|
| New bare Acts (BNS, BNSS, BSA) | 3 PDFs → `statute_*` | MHA New Criminal Laws page: `mha.gov.in/en/commoncontent/new-criminal-laws` (PDFs under `/sites/default/files/2024-04/`) | Government of India work; downloaded from official MHA URLs recorded in `data/raw/_fetch_log.json` (URL + SHA256 + date). Reproduced verbatim. |
| Bail sections (BNSS ss. 47/49/91/92/139/478–481/483/485/487/488/492, BNS s.1, BSA s.1) | 16 `ic_*` | India Code DSpace API `indiacode.gov.in/server/api`; text = `section_page_note` metadata; per-section `source_url` = `indiacode.gov.in/handle/<handle>` (header of each file in `data/raw/india_code/`) | Government of India statute text; API openly queryable, no key. Section numbers/titles come from API metadata, never from memory. |
| Bail judgments (Patna/Madras/Jharkhand/Bombay/HP/Uttarakhand HCs) | 20 `hc_*` | HF `Sumitedu/indian-case-laws` (KanoonGPT Open Legal Data Initiative), `source_pdf_s3_url` per row saved in `data/raw/_hf_bail_manifest.json` | Dataset licence **apache-2.0**. `indexable_text` is a metadata summary, not the full judgment: chunks support case-level facts (court, date, disposition) only. |
| Case files (FIR, remand, charge-sheet excerpt, medical, bail application, surety affidavit ×2 matters) | 8 `synth_*` | Generated by `corpus/make_case_files.py` | Fictional persons/events; `[SYNTHETIC]` title prefix + banner first line. Never cite as real law or cases. |

## Honest gaps

- **Old Acts (IPC/CrPC/Evidence) full text**: the new India Code site exposes
  section text only for the 2023 Acts; pre-2023 central-act sections have no
  text there (verified by querying the API). Old-law coverage is therefore
  the repeal/savings sections inside the three MHA PDFs. Full old-Act PDFs
  can be added later with `corpus/fetch_statutes.py`-style entries once an
  official bulk source is reachable.
- **Section map**: `corpus/section_map.json` has 3 rows (the three repeal
  cross-references, verbatim quotes + MHA `source_url` each). The full
  old↔new correspondence tables (BPR&D/MHA charts) were unreachable from
  this environment; attempted sources are logged in the map file and in
  `corpus/sources.py`. `build_section_map.py --chart/--chart-url` ingests an
  official chart when available; charts without an official URL are refused.
- **Judgments**: no Supreme Court bail rows in this sample (streaming order);
  headnotes only, not full opinions.

## Reproduce

```bash
.venv/bin/python corpus/fetch_statutes.py     # MHA PDFs + India Code sections -> data/raw/
.venv/bin/python corpus/fetch_judgments.py --target 20   # HF bail rows -> data/raw/hf_bail/
.venv/bin/python corpus/make_case_files.py    # synthetic files -> data/raw/synthetic/
.venv/bin/python corpus/build_corpus.py       # data/raw/ -> data/processed/ + corpus/manifest.json
.venv/bin/python corpus/build_section_map.py  # MHA PDFs -> corpus/section_map.json
.venv/bin/python eval/build_queries.py        # verify 40 spans vs data/processed/
.venv/bin/python eval/run_all.py              # every number in the write-up
```

`data/processed/` is gitignored runtime state (rebuilt above); `data/raw/`,
`corpus/*.json`, `corpus/*.md`, `eval/queries.jsonl` are committed.
